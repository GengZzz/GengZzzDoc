# 408 计算机考研

408 是计算机学科专业基础综合考试的科目代码，涵盖四门核心课程：**数据结构**、**计算机组成原理**、**操作系统**、**计算机网络**。本模块以王道考研大纲为标准，系统梳理四门课的知识体系。

## 考试概况

| 科目 | 分值 | 题型 |
|------|------|------|
| 数据结构 | 45 分 | 选择题 + 综合应用题 |
| 计算机组成原理 | 45 分 | 选择题 + 综合应用题 |
| 操作系统 | 35 分 | 选择题 + 综合应用题 |
| 计算机网络 | 25 分 | 选择题 + 综合应用题 |

::: tip 复习建议
四门课的难度和分值不同，建议按 **数据结构 → 计算机组成原理 → 操作系统 → 计算机网络** 的顺序复习。数据结构和组成原理是基础，操作系统中很多概念（如内存管理、进程调度）依赖组成原理的知识。
:::
