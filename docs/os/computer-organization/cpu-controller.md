# CPU 与控制器

CPU 是计算机的核心，负责取指、译码、执行。408 考试重点考查 CPU 结构、指令流水线、控制器设计、中断系统。

## CPU 的功能与结构

### CPU 基本功能

| 功能 | 说明 |
|------|------|
| 指令控制 | 取指、译码，保证指令按序执行 |
| 操作控制 | 产生各部件的控制信号 |
| 时间控制 | 控制各操作的时序 |
| 数据加工 | ALU 执行算术/逻辑运算 |
| 中断处理 | 响应和处理中断 |

### CPU 基本结构

```text
┌─────────────────────────────────────────────┐
│                     CPU                      │
│                                             │
│  ┌──────┐  ┌──────┐  ┌──────────────────┐  │
│  │  PC  │  │  IR  │  │   寄存器组        │  │
│  └──────┘  └──────┘  │ GPR₀ ~ GPRₙ₋₁   │  │
│                      │ SP, PSW 等       │  │
│                      └────────┬─────────┘  │
│  ┌────────────────────┐      │             │
│  │      ALU            │←─────┘             │
│  └─────────┬──────────┘                    │
│            │                               │
│  ┌─────────┴──────────┐                    │
│  │     控制单元 CU     │                    │
│  │  (产生控制信号)     │                    │
│  └─────────┬──────────┘                    │
│            │                               │
└────────────┼───────────────────────────────┘
             ↓
       内部总线 / 系统总线
```

**重要寄存器**：

| 寄存器 | 功能 |
|--------|------|
| PC | 程序计数器，存下一条指令地址 |
| IR | 指令寄存器，存当前指令 |
| MAR | 存储器地址寄存器 |
| MDR | 存储器数据寄存器 |
| PSW | 程序状态字（标志位：OF、SF、ZF、CF 等） |
| ACC | 累加器（部分架构） |

### 指令执行流程

```text
取指周期:
  1. PC → MAR          (将指令地址送地址总线)
  2. MAR → 地址总线 → 主存
  3. 主存 → MDR        (读出指令)
  4. MDR → IR          (指令送 IR)
  5. PC + 1 → PC       (PC 自增)
  6. IR(操作码) → CU   (译码)

执行周期:
  根据指令类型产生不同的微操作序列
```

## 指令流水线

### 基本概念

将指令执行划分为若干阶段，每个阶段由独立的硬件处理，实现指令级并行。

```text
经典 5 级流水线:

IF    ID    EX    MEM   WB
取指  译码  执行  访存  写回

时间 →  1    2    3    4    5    6    7
I₁:   IF → ID → EX → MEM → WB
I₂:        IF → ID → EX  → MEM → WB
I₃:             IF → ID  → EX  → MEM → WB
```

### 流水线性能指标

| 指标 | 公式 | 说明 |
|------|------|------|
| 吞吐率 | TP = n / (k + n - 1) × Δt | n 条指令，k 级流水线，时钟周期 Δt |
| 加速比 | S = k·n / (k + n - 1) | 相对于非流水线的加速 |
| 效率 | η = S / k | 流水线各段的利用率 |

::: tip 吞吐率公式推导
k 级流水线完成 n 条指令需要 k + n - 1 个时钟周期。当 n → ∞ 时，TP → 1/Δt（理想吞吐率）。
:::

### 流水线冲突

#### 结构冲突

多条指令同时需要同一硬件资源。

```text
例: IF 和 MEM 都要访问主存
解决: 分离指令 Cache 和数据 Cache（哈佛结构）
```

#### 数据冲突

后续指令依赖前面指令尚未产生的结果。

```text
RAW（写后读）: 最常见
  ADD R1, R2, R3    ; R1 ← R2 + R3
  SUB R4, R1, R5    ; R4 ← R1 - R5  (依赖 R1)

解决方法:
  1. 暂停（Stall）：插入气泡，等结果产生
  2. 数据前推（Forwarding/Bypassing）：ALU 输出直接送下一级输入
  3. 编译调度：调整指令顺序避开冲突
```

#### 控制冲突

遇到分支/跳转指令时，预取的后续指令可能不是实际要执行的。

```text
解决方法:
  1. 分支预测：静态预测（总跳/总不跳）或动态预测（历史记录）
  2. 延迟槽（MIPS）：分支后的指令总被执行
  3. 预取两条路径的指令（投机执行）
```

## 控制器设计

控制器是 CPU 的指挥中心，产生微操作控制信号。

### 硬布线控制器

用组合逻辑电路直接实现控制信号。

```text
输入: 操作码 + 时序信号 + 状态标志
       ↓
  ┌──────────┐
  │ 组合逻辑  │ → 控制信号输出
  └──────────┘
```

**特点**：速度快，但设计复杂、难以修改和扩展。适合 RISC 处理器。

### 微程序控制器

将每条指令的控制信号序列存储为微程序（微指令序列）。

```text
指令操作码 → 微地址 → 控制存储器(CM) → 微指令 → 控制信号

一条机器指令 = 一段微程序 = 多条微指令

微指令格式:
┌──────────┬──────────┬──────────┐
│ 微操作码  │ 下址字段  │ 判别测试  │
└──────────┴──────────┴──────────┘
```

**关键概念**：

| 概念 | 说明 |
|------|------|
| 微指令 | 一个时钟周期内的控制信号集合 |
| 微程序 | 实现一条机器指令的微指令序列 |
| 控制存储器 CM | 存放所有微程序，ROM 实现 |
| 微地址 | 微指令在 CM 中的地址 |
| 微命令 | 单个控制信号 |

::: tip 微程序 vs 硬布线

| 对比 | 微程序 | 硬布线 |
|------|--------|--------|
| 速度 | 较慢（需读 CM） | 快 |
| 灵活性 | 高，可修改微程序 | 低，改电路 |
| 规整性 | 规整，易于设计 | 复杂 |
| 适用 | CISC | RISC |
:::

### 微指令编码

| 方式 | 说明 |
|------|------|
| 直接编码 | 每位对应一个微命令，直观但冗余 |
| 字段直接编码 | 分组编码，每组同时只有一个微命令生效 |
| 字段间接编码 | 编码中嵌套编码，进一步压缩 |

## 中断系统

### 中断基本概念

中断是 CPU 暂停当前程序，转去处理突发事件的机制。

```text
中断处理流程:

  正常执行 → 检测到中断请求 → 关中断 → 保存断点(PC, PSW)
       → 识别中断源 → 转中断服务程序 → 开中断 → 执行服务
       → 关中断 → 恢复断点 → 开中断 → 返回原程序
```

### 中断类型

| 类型 | 说明 |
|------|------|
| 内中断（异常） | CPU 内部产生：除零、非法指令、缺页 |
| 外中断 | CPU 外部产生：I/O 完成、时钟中断 |
| 不可屏蔽中断 NMI | 必须响应：电源故障、硬件错误 |
| 可屏蔽中断 INTR | 可通过关中断屏蔽 |

### 中断判优

当多个中断同时请求时，需要判优：

| 方式 | 说明 |
|------|------|
| 软件查询 | 依次检测各设备状态，灵活但慢 |
| 硬件排队器 | 优先级编码器，速度快 |
| 菊花链 | 设备串联，靠近 CPU 的优先级高 |

### 中断屏蔽

```text
中断屏蔽字: 每位对应一个中断源
  1 = 屏蔽（不允许该中断打断当前服务）
  0 = 开放

例: 正在执行优先级 3 的中断服务
  屏蔽字 = 1111 0000
  → 优先级 0~3 的中断被屏蔽
  → 优先级 4~7 的中断可打断
```

::: tip 中断优先级与屏蔽字的关系
屏蔽字设置与优先级相关：执行优先级为 k 的服务时，屏蔽字中 0~k 位为 1（屏蔽），其余为 0。这样保证高优先级中断可打断低优先级服务，低优先级中断不能打断高优先级服务。
:::

## 高频考点总结

| 考点 | 频率 | 说明 |
|------|------|------|
| 指令流水线性能 | 极高 | 吞吐率、加速比、效率计算 |
| 流水线冲突与解决 | 极高 | 三种冲突的识别和解决方法 |
| 中断处理过程 | 高 | 中断响应、断点保存、优先级 |
| 微程序控制器 | 高 | 微指令、微地址、CM |
| CPU 数据通路 | 中 | 各寄存器与总线的连接 |
