# 数据表示与运算

计算机中所有信息都以二进制形式存储。408 考试重点考查进制转换、定点数的原/反/补码表示、补码加减运算及溢出判断、IEEE 754 浮点数。

## 进制转换

### 任意进制 → 十进制

按权展开求和。

```text
(1011.101)₂ = 1×2³ + 0×2² + 1×2¹ + 1×2⁰ + 1×2⁻¹ + 0×2⁻² + 1×2⁻³
            = 8 + 0 + 2 + 1 + 0.5 + 0 + 0.125
            = (11.625)₁₀
```

### 十进制 → 任意进制

**整数部分**：除基取余，逆序排列

```text
(43)₁₀ → 二进制:
43 ÷ 2 = 21 ... 1
21 ÷ 2 = 10 ... 1
10 ÷ 2 = 5  ... 0
 5 ÷ 2 = 2  ... 1
 2 ÷ 2 = 1  ... 0
 1 ÷ 2 = 0  ... 1
结果: (101011)₂
```

**小数部分**：乘基取整，顺序排列

```text
(0.625)₁₀ → 二进制:
0.625 × 2 = 1.25  ... 取 1
0.25  × 2 = 0.5   ... 取 0
0.5   × 2 = 1.0   ... 取 1
结果: (0.101)₂
```

::: warning 小数转换的精度问题
不是所有十进制小数都能精确转换为二进制。例如 0.1 在二进制中是无限循环小数。这会导致浮点数精度问题。
:::

### 二进制 ↔ 八进制 / 十六进制

| 进制 | 转换规则 |
|------|---------|
| 二 → 八 | 每 3 位一组 |
| 二 → 十六 | 每 4 位一组 |

```text
(10 101 011.101 100)₂ → 八进制
  2   5   3  .  5   4
= (253.54)₈

(0010 1010 1011.1011)₂ → 十六进制
   2    A    B  .  B
= (2AB.B)₁₆
```

## 定点数表示

定点数中小数点位置固定。通常用**定点整数**（小数点在最低位之后）和**定点小数**（小数点在最高位之前）。

### 无符号数

所有位都表示数值。n 位无符号数范围：0 ~ 2ⁿ-1。

### 原码

最高位为符号位（0 正 1 负），其余位为数值的绝对值。

```text
[+5]原 = 0,0101    [−5]原 = 1,0101

n 位原码（含 1 位符号位）范围: -(2ⁿ⁻¹-1) ~ +(2ⁿ⁻¹-1)
```

**问题**：0 有两种表示（+0 = 0000，-0 = 1000），加减运算复杂。

### 反码

正数的反码 = 原码；负数的反码 = 符号位不变，数值位取反。

```text
[+5]反 = 0,0101    [−5]反 = 1,1010
```

反码只是求补码的中间过程，实际中很少直接使用。

### 补码（核心）

正数的补码 = 原码；负数的补码 = 反码 + 1。

```text
[+5]补 = 0,0101
[−5]补: 原码 1,0101 → 反码 1,1010 → +1 → 1,1011

验证: 0,0101 + 1,1011 = [1]0,0000 (溢出位丢弃) = +0 ✓
```

**为什么用补码**：
1. 0 只有一种表示（0000）
2. 减法变加法：A - B = A + (-B)补
3. 符号位参与运算，结果自然正确

```text
7 - 3 = 7 + (-3):

  0,0111  (+7 的补码)
+ 1,1101  (-3 的补码)
----------
 [1]0,0100  (溢出位丢弃) = +4 ✓
```

**n 位补码范围**：-2ⁿ⁻¹ ~ +(2ⁿ⁻¹-1)

::: tip 补码的快速求法
从右向左找到第一个 1，这个 1 及其右边的位不变，左边的位（除符号位）取反。

例：[-27]补 → |27|=0001 1011 → 从右找第一个 1 → 1110 0101
:::

### 移码

补码的符号位取反。移码用于浮点数的阶码，因为移码比较大小方便。

```text
[+5]移 = 1,0101    [−5]移 = 0,1011
```

### 真值与各码对照表（4 位，含 1 位符号位）

| 真值 | 原码 | 反码 | 补码 | 移码 |
|------|------|------|------|------|
| +0 | 0000 | 0000 | 0000 | 1000 |
| -0 | 1000 | 1111 | 0000 | 1000 |
| +1 | 0001 | 0001 | 0001 | 1001 |
| -1 | 1001 | 1110 | 1111 | 0111 |
| +7 | 0111 | 0111 | 0111 | 1111 |
| -7 | 1111 | 1000 | 1001 | 0001 |
| -8 | — | — | 1000 | 0000 |

::: warning 补码的特殊值
补码 -8 = 1000，没有对应的原码。补码比原码多表示一个 -2ⁿ⁻¹。
:::

## 定点数运算

### 补码加减运算

**公式**：[A + B]补 = [A]补 + [B]补，[A - B]补 = [A]补 + [-B]补

```text
减法转加法: 需要先求 [-B]补（方法：[B]补 连同符号位取反加 1）
```

**溢出判断**：

两种溢出：
- **正溢出**：两个正数相加，结果为负
- **负溢出**：两个负数相加，结果为正

判断方法：

| 方法 | 规则 |
|------|------|
| 单符号位 | 若参加运算的两个数符号相同，但结果符号不同，则溢出 |
| 双符号位（变形补码） | 两个符号位不同即溢出：01 正溢，10 负溢 |

```text
正溢出: (+6) + (+5) = +11 (4 位补码装不下)
  0,0110 + 0,0101 = 0,1011 → 符号位为 0 但数值溢出

负溢出: (-6) + (-5) = -11
  1,1010 + 1,1011 = [1]1,0101 → 符号位变 1，但数值超出范围
```

::: tip 溢出判断的三种方式
1. **符号位判断**：同号相加，结果符号与操作数不同 → 溢出
2. **进位判断**：最高数值位进位 ⊕ 符号位进位 = 1 → 溢出
3. **双符号位**：两个符号位不同 → 溢出（01 正溢，10 负溢）
:::

### 乘除运算

**原码一位乘法**：符号位单独处理，数值位逐位乘加，类似手算乘法。

**补码乘法（Booth 算法）**：直接对补码操作，不需要转换为原码。根据乘数相邻两位的组合来决定加/减被乘数。

**除法**：原码恢复余数法和加减交替法。补码除法使用加减交替法。

## 浮点数表示

### 一般格式

```text
N = (-1)ˢ × M × 2ᴱ

s: 符号位（0 正 1 负）
M: 尾数（定点小数，范围 [1,2) ）
E: 阶码（定点整数）
```

```text
浮点数格式:
┌──────┬──────────┬──────────────────────┐
│ 阶符 │  阶码 E  │  数符 │    尾数 M     │
└──────┴──────────┴──────────────────────┘
```

### IEEE 754 标准

| 类型 | 总位数 | 符号 | 阶码 | 尾数 | 偏置值 |
|------|--------|------|------|------|--------|
| 单精度 float | 32 | 1 | 8 | 23 | 127 |
| 双精度 double | 64 | 1 | 11 | 52 | 1023 |

```text
32 位单精度:
 31  30────23  22──────────────0
┌───┬────────┬───────────────────┐
│ S │ 阶码 E │     尾数 M        │
└───┴────────┴───────────────────┘

真值 = (-1)ˢ × 1.M × 2^(E-127)    (规格化时隐藏最高位 1)
```

**特殊值**：

| 阶码 E | 尾数 M | 含义 |
|--------|--------|------|
| 0 | 0 | ±0 |
| 255 | 0 | ±∞ |
| 255 | 非 0 | NaN（非数） |
| 0 | 非 0 | 非规格化数 |

::: tip 规格化数的隐含位
规格化浮点数的尾数最高位一定是 1，IEEE 754 省略存储这个 1（隐含位），实际尾数多一位精度。
:::

### 浮点数转换

**十进制 → IEEE 754 单精度**：

```text
例: (-13.625)₁₀

1. 符号位: 负数 → S = 1
2. 整数部分: 13 = 1101₂
3. 小数部分: 0.625 = 0.101₂
4. 合并: 1101.101 = 1.101101 × 2³
5. 阶码: E = 3 + 127 = 130 = 10000010
6. 尾数: 10110100000000000000000（省略隐含的 1）

结果: 1 10000010 10110100000000000000000
十六进制: C1 54 00 00
```

### 浮点数加减运算

1. **对阶**：小阶向大阶看齐，尾数右移（阶差 = |E₁ - E₂|）
2. **尾数加减**：对阶后的尾数做定点加减
3. **规格化**：调整尾数和阶码，使尾数在 [1, 2) 范围
4. **舍入**：右移丢失精度时进行舍入（0 舍 1 入、恒置 1 等）
5. **溢出判断**：判断阶码是否溢出

::: warning 对阶导致精度丢失
对阶时右移尾数，低位被丢弃。如果小阶和大阶差距很大，可能导致精度严重丢失。这也是浮点数不精确的原因之一。
:::

## 算术逻辑单元（ALU）

ALU 是 CPU 中执行算术和逻辑运算的部件。

```text
ALU 输入: A(n位), B(n位), 操作码 F
ALU 输出: F(n位), 状态标志

标志位:
- OF: 溢出标志（有符号溢出）
- SF: 符号标志（结果为负）
- ZF: 零标志（结果为 0）
- CF: 进位标志（无符号溢出）
```
