# 存储系统

存储系统是组成原理的核心章节。408 考试重点考查存储器层次结构、主存容量扩展、Cache 映射及命中率计算。

## 存储器层次结构

```text
          速度快、容量小、价格高
                ┌─────┐
                │寄存器│  ← CPU 内部
                ├─────┤
                │Cache │  ← SRAM
                ├─────┤
                │ 主存  │  ← DRAM
                ├─────┤
                │辅存   │  ← 磁盘/SSD
                └─────┘
          速度慢、容量大、价格低
```

**层次结构的依据**：程序局部性原理
- **时间局部性**：刚被访问的数据很可能再次被访问
- **空间局部性**：被访问数据附近的数据很可能被访问

::: tip 两个核心公式
- **Cache-主存层次**：解决 CPU 与主存速度差距
- **主存-辅存层次**：解决容量需求，虚拟存储器的基础
:::

## 主存储器

### SRAM vs DRAM

| 对比 | SRAM（静态） | DRAM（动态） |
|------|------------|------------|
| 存储原理 | 触发器 | 电容 |
| 速度 | 快 | 慢 |
| 集成度 | 低 | 高 |
| 功耗 | 大 | 小 |
| 刷新 | 不需要 | 需要定期刷新 |
| 用途 | Cache | 主存 |
| 价格 | 贵 | 便宜 |

### DRAM 刷新方式

| 刷新方式 | 说明 |
|---------|------|
| 集中刷新 | 一段连续时间集中刷新，期间不能访存（死时间） |
| 分散刷新 | 每次读写后顺便刷新，无死时间但速度慢 |
| 异步刷新 | 将刷新周期均分，每隔一段时间刷新一行 |

### ROM 类型

| 类型 | 特点 |
|------|------|
| MROM | 出厂时写入，不可修改 |
| PROM | 一次可编程 |
| EPROM | 紫外线擦除，可多次编程 |
| EEPROM | 电擦除，可多次编程 |
| Flash | U盘、SSD 的存储介质 |

## 主存容量扩展

当单个存储芯片容量不够时，需要多片组合扩展。

### 位扩展

增加数据位宽。各芯片地址线、片选线并联，数据线分别连接。

```text
用 8 片 16K×1 位的芯片 → 16K×8 位的存储器

地址线: 各芯片 A0-A13 并联
数据线: 各芯片 D0-D7 分别连一根
片选线: 全部并联（同时选中）
```

### 字扩展

增加存储单元数。各芯片数据线并联，用地址译码器区分。

```text
用 4 片 16K×8 位的芯片 → 64K×8 位的存储器

数据线: 各芯片 D0-D7 并联
地址线: 高 2 位 A14-A15 连译码器 → 4 个片选信号
        低 14 位 A0-A13 连各芯片
```

### 字位同时扩展

同时增加位宽和字数。

```text
用 8 片 16K×4 位的芯片 → 64K×8 位的存储器

先位扩展: 2 片一组 → 16K×8 位（4 组）
再字扩展: 4 组 → 64K×8 位
```

::: tip 扩展计算公式
- 总芯片数 = (目标容量/单片容量) × (目标位数/单片位数)
- 地址线位数 = log₂(存储单元数)
- 数据线位数 = 存储字长
:::

## Cache

Cache 位于 CPU 和主存之间，存放主存中当前最活跃的数据块。

### Cache 的基本原理

```text
CPU → 查 Cache
  命中 (Hit): 直接从 Cache 读取 → 速度 = Cache 速度
  未命中 (Miss): 从主存读取 → 先调入 Cache，再给 CPU
```

**命中率**：H = Nc / (Nc + Nm)

**平均访问时间**：
- 先访问 Cache，不命中再访问主存：`ta = H × tc + (1-H) × (tc + tm)`
- 同时访问 Cache 和主存：`ta = H × tc + (1-H) × tm`

### Cache 与主存的映射方式

#### 直接映射

主存块只能映射到 Cache 的固定位置：`Cache 行号 = 主存块号 mod Cache 行数`

```text
主存地址划分:
┌──────────┬──────────┬──────────┐
│  标记 Tag │  行号    │  块内地址 │
└──────────┴──────────┴──────────┘

主存块 0, 8, 16, ... 都映射到 Cache 第 0 行
主存块 1, 9, 17, ... 都映射到 Cache 第 1 行
```

**优点**：查找简单（只需比较一个 Tag）
**缺点**：冲突率高，Cache 利用率低

#### 全相联映射

主存块可以映射到 Cache 的任意位置。

```text
主存地址划分:
┌──────────────────┬──────────┐
│      标记 Tag     │ 块内地址 │
└──────────────────┴──────────┘
```

**优点**：冲突率最低，Cache 利用率最高
**缺点**：查找复杂（需要比较所有 Tag）

#### 组相联映射

将 Cache 分成若干组，主存块映射到固定组，组内任意位置：`Cache 组号 = 主存块号 mod Cache 组数`

```text
2 路组相联: Cache 分为 4 组，每组 2 行
主存块 0, 4, 8, ... 映射到第 0 组（组内 2 个位置可选）
主存块 1, 5, 9, ... 映射到第 1 组

主存地址划分:
┌──────────┬──────────┬──────────┐
│  Tag     │  组号    │ 块内地址 │
└──────────┴──────────┴──────────┘
```

**优点**：折中方案，冲突率和查找复杂度都适中
**实际应用**：L1 Cache 通常使用 2-8 路组相联

::: tip 三种映射方式对比
| 方式 | 直接映射 | 全相联 | 组相联 |
|------|---------|--------|--------|
| 冲突率 | 高 | 低 | 中 |
| 查找速度 | 快 | 慢 | 中 |
| 硬件成本 | 低 | 高 | 中 |
:::

### 替换算法

Cache 满时需要替换某一行：

| 算法 | 规则 | 实现 |
|------|------|------|
| FIFO | 先进先出 | 计数器 |
| LRU | 最近最久未使用 | 计数器/栈 |
| 随机法 | 随机替换 | 硬件简单 |

::: tip LRU 最常用
LRU 近似实现：为每行设一个计数器，每次命中时该行清零，其余行+1。替换时选计数器值最大的行。
:::

### 写策略

| 策略 | 写命中 | 写不命中 |
|------|--------|---------|
| 全写法 | 同时写 Cache 和主存 | 直接写主存 |
| 写回法 | 只写 Cache，设脏位 | 写分配（先调入再写） |

- **全写法**：Cache 和主存始终一致，不需要脏位，但写操作慢
- **写回法**：写操作快，但需要脏位（dirty bit）标记被修改的块

## 虚拟存储器

虚拟存储器（Virtual Memory）建立在主存-辅存层次上，为每个进程提供一个独立的虚拟地址空间。

### 基本原理

```text
虚拟地址 → 页表查询 → 物理地址
  页号 → 查页表 → 物理页框号
  页内偏移 → 直接传递

虚拟地址: ┌──────────┬──────────────┐
          │  虚拟页号 │  页内偏移     │
          └──────────┴──────────────┘
                           ↓
物理地址: ┌──────────┬──────────────┐
          │ 物理页框号│  页内偏移     │
          └──────────┴──────────────┘
```

### 快表（TLB）

页表存放在主存中，每次地址转换需要访存。TLB（Translation Lookaside Buffer）是页表的 Cache。

```text
有 TLB 的地址转换:
1. 查 TLB → 命中则直接得到物理页框号
2. TLB 未命中 → 查主存页表 → 更新 TLB
3. 页表项不在主存 → 缺页中断 → 从辅存调入
```

**有效访问时间**：`EAT = α × (t_TLB + t_cache + t_mem) + (1-α) × (t_TLB + t_mem + t_cache + t_mem)`（简化模型）

### 页表

| 页表项 | 含义 |
|--------|------|
| 物理页框号 | 虚拟页对应的物理页框 |
| 有效位 | 该页是否在主存中 |
| 修改位（脏位） | 该页是否被修改过 |
| 引用位 | 用于替换算法（LRU） |
| 保护位 | 读/写/执行权限 |

::: tip Cache vs 虚拟存储器
| 对比 | Cache | 虚拟存储器 |
|------|-------|-----------|
| 介于 | CPU-主存 | 主存-辅存 |
| 块/页大小 | 几十字节~几百字节 | 几KB~几MB |
| 管理 | 硬件 | 硬件+OS |
:::

## 高频考点总结

| 考点 | 频率 | 说明 |
|------|------|------|
| Cache 三种映射方式 | 极高 | 地址划分、Tag 计算 |
| Cache 命中率/平均访存时间 | 极高 | 公式计算 |
| 主存容量扩展 | 高 | 位扩展、字扩展、字位扩展 |
| LRU 替换算法 | 高 | 计数器变化过程 |
| 虚拟地址转换 + TLB | 高 | 有效访问时间计算 |
| 写策略 | 中 | 全写 vs 写回 |
| SRAM vs DRAM | 中 | 对比表 |
