# 物理层与数据链路层

物理层负责比特传输，数据链路层负责帧传输。408 考试重点考查信道容量计算、编码方式、CSMA/CD、滑动窗口。

## 物理层

### 信道容量

#### 奈奎斯特定理（无噪声）

**理想信道最大数据率** = 2W × log₂V（bps）

- W：信道带宽（Hz）
- V：信号离散电平数

```text
例：信道带宽 3kHz，4 个电平
最大数据率 = 2 × 3000 × log₂4 = 12000 bps
```

#### 香农定理（有噪声）

**信道极限数据率** = W × log₂(1 + S/N)（bps）

- S/N：信噪比（信号功率/噪声功率）
- 信噪比常用 dB 表示：dB = 10 × log₁₀(S/N)

```text
例：信道带宽 3kHz，信噪比 30dB
S/N = 10^(30/10) = 1000
最大数据率 = 3000 × log₂(1+1000) ≈ 3000 × 10 = 30000 bps
```

::: tip 两者取较小值
实际信道的最大数据率 = min(奈奎斯特值, 香农值)。奈奎斯特给出上限，香农考虑了噪声限制。
:::

### 编码与调制

#### 数字数据编码

| 编码 | 特点 |
|------|------|
| 不归零码 NRZ | 1 高电平，0 低电平。无法自同步 |
| 曼彻斯特编码 | 每个比特中间跳变：1 是高→低，0 是低→高。以太网采用 |
| 差分曼彻斯特编码 | 每个比特开始有跳变为 0，无跳变为 1 |

```text
数据:    1     0     1     1     0

NRZ:    ┌──┐  ┌─────┐  ┌─────┐  ┌──┐
        │  │  │     │  │     │  │  │
    ────┘  └──┘     └──┘     └──┘  └──

曼彻斯特:
        ──┐┌──┐  ┌──┐  ┌──┐  ┌──┐
          └┘  └──┘  └──┘  └──┘  └──
```

## 数据链路层

### 基本功能

| 功能 | 说明 |
|------|------|
| 封装成帧 | 添加帧头帧尾，标识帧边界 |
| 透明传输 | 处理数据中可能出现的帧定界符 |
| 差错控制 | 检测或纠正传输错误 |
| 流量控制 | 控制发送速率，避免接收方溢出 |
| 介质访问控制 | 多设备共享信道时的接入规则 |

### 差错控制

#### CRC 循环冗余校验

```text
发送方:
1. 选定生成多项式 G(x)（长度 n+1 位）
2. 数据后补 n 个 0
3. 模 2 除法（异或）得到 n 位余数
4. 余数附加到数据后发送

例: 数据 101001, G(x) = 1101 (n=3)
101001 000 ÷ 1101 = ... 余 001
发送: 101001 001

接收方:
收到的数据 ÷ G(x)，余数为 0 则无错
```

::: tip CRC 只能检错不能纠错
CRC 能检测出所有单比特错误、所有双比特错误、所有奇数个比特错误。要纠错需要海明码。
:::

#### 海明码

在数据位之间插入校验位，可检错和纠错。

**校验位个数** r：2^r ≥ m + r + 1（m 为数据位数）

校验位放在 2 的幂次位置（1, 2, 4, 8, ...），每个校验位覆盖若干数据位。

### 流量控制

#### 停止-等待协议

```text
发送 1 帧 → 等待 ACK → 收到 ACK → 发送下一帧
超时未收到 ACK → 重传

效率低: 大部分时间在等待
```

#### 滑动窗口

| 类型 | 发送窗口 | 接收窗口 | 说明 |
|------|---------|---------|------|
| 停止-等待 | 1 | 1 | GBN = 1 的特例 |
| GBN（回退 N 帧） | >1 | 1 | 出错从出错帧开始重传所有后续帧 |
| SR（选择重传） | >1 | >1 | 只重传出错的帧 |

```text
GBN 示例（窗口大小 4）:

发送方窗口: [1][2][3][4]  5  6  7
              发送 →
帧 2 出错: 从帧 2 开始重传 [2][3][4]...
帧 1 已确认, 帧 2~4 都要重传

SR 示例（窗口大小 4）:
帧 2 出错: 只重传帧 2
帧 1, 3, 4 正常接收，存入缓冲区
收到帧 2 后按序交付
```

::: tip 窗口大小限制
GBN: 发送窗口 ≤ 2^n - 1（n 位编号）
SR: 发送窗口 + 接收窗口 ≤ 2^n，通常 Ws = Wr = 2^(n-1)
:::

### 介质访问控制

#### CSMA/CD（以太网）

载波侦听多路访问 / 碰撞检测。

```text
1. 先听后发: 发送前监听信道
2. 边发边听: 发送时检测碰撞
3. 碰撞停发: 检测到碰撞立即停止
4. 随机重传: 等待随机时间后重传

最小帧长 = 2 × 传播时延 × 带宽
（确保在发送完毕前检测到碰撞）
```

#### CSMA/CA（无线局域网）

载波侦听多路访问 / 碰撞避免。

```text
与 CD 的区别: 无线信号无法边发边听（信号强度差太大）
解决: 发送前预约信道（RTS/CTS）

1. 检测到空闲 → 等待 DIFS → 发送
2. 收到 → 回复 ACK
3. 未收到 ACK → 退避重传
```

::: tip CSMA/CD vs CSMA/CA
- CD: 有线以太网，边发边检测碰撞，检测到就停
- CA: 无线 Wi-Fi，通过 RTS/CTS 预约避免碰撞
- CD 要求最小帧长，CA 不需要
:::

### 局域网

#### 以太网帧格式

```text
┌──────┬──────┬──────┬──────┬──────┬──────┐
│前导码 │目的MAC│源MAC│ 类型 │ 数据 │ FCS  │
│ 8B   │ 6B   │ 6B  │ 2B  │46~1500│ 4B  │
└──────┴──────┴──────┴──────┴──────┴──────┘
```

#### MAC 地址

48 位（6 字节），全球唯一，烧录在网卡中。

```text
格式: XX:XX:XX:XX:XX:XX（十六进制）
前 24 位: 厂商标识（OUI）
后 24 位: 设备标识
```
