# 体系结构

计算机网络的体系结构定义了网络的分层模型和协议栈。408 考试重点考查 OSI 七层模型、TCP/IP 四层模型以及各层的功能划分。

## 网络概述

### 网络定义与分类

计算机网络是将分散的、具有独立功能的计算机系统，通过通信设备和线路连接起来，由功能完善的软件实现资源共享和信息传递的系统。

| 分类依据 | 类型 | 说明 |
|---------|------|------|
| 覆盖范围 | LAN（局域网） | 几百米~几公里，如校园网 |
| | MAN（城域网） | 一个城市范围 |
| | WAN（广域网） | 跨城市/国家/洲 |
| 拓扑结构 | 总线型、星型、环型、网状型 | 物理连接方式 |
| 传输技术 | 广播式、点对点 | 数据传输方式 |

### 网络性能指标

| 指标 | 说明 | 单位 |
|------|------|------|
| 速率 | 数据传输速率 | bps、Kbps、Mbps |
| 带宽 | 最高数据率（信道容量） | bps |
| 吞吐量 | 单位时间实际通过的数据量 | bps |
| 时延 | 数据从发送到接收的总时间 | ms |
| 时延带宽积 | 传播时延 × 带宽 = 管道中比特数 | bit |
| 往返时延 RTT | 发送方到接收方来回的时间 | ms |

**总时延** = 发送时延 + 传播时延 + 处理时延 + 排队时延

```text
发送时延 = 数据长度 / 发送速率    （在发送器内）
传播时延 = 信道长度 / 电磁波速率  （在信道中）
```

::: tip 发送时延 vs 传播时延
发送时延取决于发送速率（带宽），传播时延取决于信道长度和介质。高速链路减少的是发送时延，不改变传播时延。
:::

## OSI 七层模型

| 层 | 名称 | 功能 | 数据单位 | 典型协议/设备 |
|----|------|------|---------|-------------|
| 7 | 应用层 | 用户接口，提供网络服务 | 数据 | HTTP、FTP、SMTP、DNS |
| 6 | 表示层 | 数据格式转换、加密/解密 | 数据 | JPEG、SSL |
| 5 | 会话层 | 建立、管理、终止会话 | 数据 | — |
| 4 | 传输层 | 端到端的可靠传输 | 报文段 | TCP、UDP |
| 3 | 网络层 | 路由选择、逻辑寻址 | 数据报 | IP、ICMP、ARP |
| 2 | 数据链路层 | 帧传输、差错控制 | 帧 | 以太网、PPP |
| 1 | 物理层 | 比特传输 | 比特 | — |

```text
发送方（自上而下封装）:

应用层: [数据]
传输层: [TCP/UDP头][数据]             → 报文段
网络层: [IP头][TCP/UDP头][数据]        → 数据报
数据链路层: [帧头][IP头][TCP/UDP头][数据][帧尾] → 帧
物理层: 0101010101...                   → 比特流
```

## TCP/IP 四层模型

| 层 | 对应 OSI | 主要协议 |
|----|---------|---------|
| 应用层 | 7+6+5 | HTTP、FTP、SMTP、DNS、DHCP |
| 传输层 | 4 | TCP、UDP |
| 网络层 | 3 | IP、ICMP、ARP、IGMP |
| 网络接口层 | 2+1 | 以太网、Wi-Fi、PPP |

## 五层参考模型

教学中最常用，结合了 OSI 的清晰分层和 TCP/IP 的实用性。

```text
┌────────────────────────────┐
│        应用层               │  HTTP、FTP、DNS
├────────────────────────────┤
│        传输层               │  TCP、UDP
├────────────────────────────┤
│        网络层               │  IP、ICMP、ARP
├────────────────────────────┤
│       数据链路层             │  以太网、PPP
├────────────────────────────┤
│        物理层               │  比特传输
└────────────────────────────┘
```

## 协议、接口、服务

| 概念 | 说明 |
|------|------|
| 协议 | 对等层之间的规则集合（语法、语义、同步） |
| 接口 | 同一系统中相邻层之间交换信息的边界 |
| 服务 | 下层为上层提供的功能（通过原语调用） |

### 服务类型

| 类型 | 说明 |
|------|------|
| 面向连接 | 通信前建立连接，传输中维护，结束后释放 |
| 无连接 | 每个分组独立路由，不维护连接状态 |
| 可靠服务 | 有确认、重传机制（如 TCP） |
| 不可靠服务 | 尽力而为，不保证交付（如 UDP、IP） |

::: tip OSI 与 TCP/IP 的对比
OSI 概念清晰但过于复杂，实现困难；TCP/IP 先有协议后有模型，实用性强，是互联网的事实标准。408 考试通常以五层模型为基准。
:::

## 高频考点总结

| 考点 | 频率 | 说明 |
|------|------|------|
| OSI 七层 vs TCP/IP 四层 | 极高 | 各层功能、对应关系 |
| 各层的协议和数据单位 | 极高 | 每层对应什么协议、传输单位是什么 |
| 时延计算 | 高 | 发送时延 + 传播时延 |
| 协议三要素 | 中 | 语法、语义、同步 |
| 面向连接 vs 无连接 | 中 | TCP vs UDP 的区别 |
