# 排序

排序是数据结构的核心内容。408 考试重点考查各排序算法的原理、手动模拟、时间空间复杂度和稳定性。

## 基本概念

**稳定性**：若排序前后相等元素的相对位置不变，则称排序算法是**稳定**的。

**内部排序**：数据全部在内存中完成的排序。

**外部排序**：数据量太大无法一次装入内存，需要在内外存之间交换数据的排序。

## 插入排序

### 直接插入排序

将待排序元素插入到已排序序列的合适位置。

```c
void InsertSort(int A[], int n) {
    for (int i = 2; i <= n; i++) {    // 从第 2 个元素开始
        if (A[i] < A[i - 1]) {
            A[0] = A[i];              // 哨兵
            int j;
            for (j = i - 1; A[0] < A[j]; j--)  // 从后往前找位置
                A[j + 1] = A[j];      // 后移
            A[j + 1] = A[0];          // 插入
        }
    }
}
```

| 性质 | 复杂度 |
|------|--------|
| 最好（已有序） | O(n) |
| 最坏（逆序） | O(n²) |
| 平均 | O(n²) |
| 空间 | O(1) |
| 稳定性 | 稳定 |

### 折半插入排序

用折半查找确定插入位置，减少比较次数，但移动次数不变。

```c
void BinaryInsertSort(int A[], int n) {
    for (int i = 2; i <= n; i++) {
        A[0] = A[i];
        int low = 1, high = i - 1;
        while (low <= high) {
            int mid = (low + high) / 2;
            if (A[mid] > A[0]) high = mid - 1;
            else low = mid + 1;
        }
        for (int j = i - 1; j >= low; j--)  // 后移
            A[j + 1] = A[j];
        A[low] = A[0];
    }
}
```

**时间复杂度**：O(n²)（比较 O(n log n) + 移动 O(n²)），稳定。

### 希尔排序

将序列按步长 d 分组，每组进行直接插入排序，逐步缩小 d 直到 d=1。

```c
void ShellSort(int A[], int n) {
    for (int d = n / 2; d >= 1; d /= 2) {  // 步长递减
        for (int i = d + 1; i <= n; i++) {
            if (A[i] < A[i - d]) {
                A[0] = A[i];
                int j;
                for (j = i - d; j > 0 && A[0] < A[j]; j -= d)
                    A[j + d] = A[j];
                A[j + d] = A[0];
            }
        }
    }
}
```

```text
步长 d=4 时的分组示例:

  [49, 38, 65, 97, 76, 13, 27, 49*, 55, 4]
   ①       ②       ③       ①       ②
      ③       ①       ②       ③

  ①组: 49, 76, 49*   → 组内直接插入排序
  ②组: 38, 13, 55    → 组内直接插入排序
  ③组: 65, 97, 27, 4 → 组内直接插入排序
```

**时间复杂度**：依赖于步长序列，约为 O(n^1.3)，**不稳定**。

## 交换排序

### 冒泡排序

相邻元素两两比较，每趟将最大元素"冒泡"到末尾。

```c
void BubbleSort(int A[], int n) {
    for (int i = 0; i < n - 1; i++) {
        bool flag = false;
        for (int j = n - 1; j > i; j--) {
            if (A[j - 1] > A[j]) {
                swap(A[j - 1], A[j]);
                flag = true;
            }
        }
        if (!flag) break;  // 本趟未发生交换，已有序
    }
}
```

| 性质 | 复杂度 |
|------|--------|
| 最好（已有序） | O(n) |
| 最坏（逆序） | O(n²) |
| 空间 | O(1) |
| 稳定性 | 稳定 |

### 快速排序

选一个**枢轴（pivot）**，将数组划分为"小于枢轴"和"大于枢轴"两部分，递归处理。

```c
int Partition(int A[], int low, int high) {
    int pivot = A[low];  // 选第一个元素为枢轴
    while (low < high) {
        while (low < high && A[high] >= pivot) high--;
        A[low] = A[high];
        while (low < high && A[low] <= pivot) low++;
        A[high] = A[low];
    }
    A[low] = pivot;
    return low;
}

void QuickSort(int A[], int low, int high) {
    if (low < high) {
        int pivotpos = Partition(A, low, high);
        QuickSort(A, low, pivotpos - 1);
        QuickSort(A, pivotpos + 1, high);
    }
}
```

```text
Partition 过程示例:

pivot = 49
[49, 38, 65, 97, 76, 13, 27]
 ↑low                      ↑high

1. high 从右找 <49 的: 找到 27 → A[low]=27
2. low 从左找 >49 的: 找到 65 → A[high]=65
3. high 从右找 <49 的: 找到 13 → A[low]=13
4. low 从左找 >49 的: 找到 97 → A[high]=97
5. high 从右找 <49 的: high==low, 结束
A[low]=49

结果: [27, 38, 13] 49 [76, 97, 65]
```

| 性质 | 复杂度 |
|------|--------|
| 最好（每次均匀划分） | O(n log n) |
| 最坏（已有序，退化） | O(n²) |
| 平均 | O(n log n) |
| 空间 | O(log n)~O(n)（递归栈） |
| 稳定性 | **不稳定** |

::: warning 快排的不稳定性
例：[3, 3*, 2]，pivot=3 时，3* 会被换到 3 前面，相对位置改变。
:::

::: tip 快排是内部排序中平均性能最好的
快排的平均时间复杂度 O(n log n)，常数因子小，是实际应用中最常用的排序算法。但它是**不稳定**的，需要稳定排序时不能选。
:::

## 选择排序

### 简单选择排序

每趟从未排序部分选出最小元素，放到已排序部分的末尾。

```c
void SelectSort(int A[], int n) {
    for (int i = 0; i < n - 1; i++) {
        int min = i;
        for (int j = i + 1; j < n; j++)
            if (A[j] < A[min]) min = j;
        if (min != i) swap(A[i], A[min]);
    }
}
```

**时间复杂度**：O(n²)，空间 O(1)，**不稳定**。

### 堆排序

利用堆这种数据结构进行排序。堆是一棵完全二叉树，满足：

- **大根堆**：每个结点的值 ≥ 其孩子结点的值
- **小根堆**：每个结点的值 ≤ 其孩子结点的值

```c
// 调整以 k 为根的子树为大根堆
void HeadAdjust(int A[], int k, int len) {
    A[0] = A[k];  // 暂存
    for (int i = 2 * k; i <= len; i *= 2) {
        if (i < len && A[i] < A[i + 1]) i++;  // 取较大孩子
        if (A[0] >= A[i]) break;
        A[k] = A[i];  // 孩子上移
        k = i;
    }
    A[k] = A[0];
}

void BuildMaxHeap(int A[], int len) {
    for (int i = len / 2; i >= 1; i--)  // 从最后一个非叶结点开始
        HeadAdjust(A, i, len);
}

void HeapSort(int A[], int len) {
    BuildMaxHeap(A, len);
    for (int i = len; i > 1; i--) {
        swap(A[1], A[i]);     // 堆顶与末尾交换
        HeadAdjust(A, 1, i - 1);  // 调整剩余为大根堆
    }
}
```

```text
建堆过程示例 (大根堆):

初始完全二叉树:          调整后的大根堆:
      4                      9
     / \                    / \
    2   7      →           5   7
   / \ / \                / \ / \
  1  5 3  9              1  2 3  4
```

| 性质 | 复杂度 |
|------|--------|
| 建堆 | O(n) |
| 每次调整 | O(log n) |
| 总时间 | O(n log n) |
| 空间 | O(1) |
| 稳定性 | **不稳定** |

::: tip 堆的用途

1. 堆排序：O(n log n)，适合数据量大的场景
2. 优先队列：每次取最大/最小元素
3. Top-K 问题：用小根堆找最大的 K 个元素
:::

## 归并排序

将两个有序子序列合并为一个有序序列。

```c
int *B = (int *)malloc((n + 1) * sizeof(int));  // 辅助数组

void Merge(int A[], int low, int mid, int high) {
    for (int k = low; k <= high; k++) B[k] = A[k];
    int i = low, j = mid + 1, k = low;
    while (i <= mid && j <= high) {
        if (B[i] <= B[j]) A[k++] = B[i++];  // <= 保证稳定性
        else A[k++] = B[j++];
    }
    while (i <= mid) A[k++] = B[i++];
    while (j <= high) A[k++] = B[j++];
}

void MergeSort(int A[], int low, int high) {
    if (low < high) {
        int mid = (low + high) / 2;
        MergeSort(A, low, mid);
        MergeSort(A, mid + 1, high);
        Merge(A, low, mid, high);
    }
}
```

| 性质 | 复杂度 |
|------|--------|
| 时间（所有情况） | O(n log n) |
| 空间 | O(n) |
| 稳定性 | **稳定** |

::: tip 归并排序的特点
归并排序是唯一在**所有情况下**都是 O(n log n) 的内部排序算法。代价是需要 O(n) 额外空间。也是**稳定**的。
:::

## 基数排序

按关键字的每一位进行排序，从低位到高位（LSD）或从高位到低位（MSD）。

```text
对 [278, 109, 063, 930, 589, 184, 505, 269, 008, 892] 排序:

第 1 趟（个位）: 930, 892, 063, 184, 505, 278, 008, 109, 589, 269
第 2 趟（十位）: 505, 008, 109, 930, 063, 269, 278, 184, 589, 892
第 3 趟（百位）: 008, 063, 109, 184, 269, 278, 505, 589, 892, 930
```

**时间复杂度**：O(d(n+r))，d 为关键字位数，r 为基数（如 10 进制 r=10）

**特点**：不需要比较，**稳定**，适合关键字位数少、取值范围小的情况。

## 排序算法总对比

| 算法 | 最好 | 平均 | 最坏 | 空间 | 稳定性 |
|------|------|------|------|------|--------|
| 直接插入 | O(n) | O(n²) | O(n²) | O(1) | 稳定 |
| 折半插入 | O(n log n)¹ | O(n²) | O(n²) | O(1) | 稳定 |
| 希尔排序 | — | O(n^1.3) | — | O(1) | **不稳定** |
| 冒泡排序 | O(n) | O(n²) | O(n²) | O(1) | 稳定 |
| 快速排序 | O(n log n) | O(n log n) | O(n²) | O(log n) | **不稳定** |
| 简单选择 | O(n²) | O(n²) | O(n²) | O(1) | **不稳定** |
| 堆排序 | O(n log n) | O(n log n) | O(n log n) | O(1) | **不稳定** |
| 归并排序 | O(n log n) | O(n log n) | O(n log n) | O(n) | 稳定 |
| 基数排序 | O(d(n+r)) | O(d(n+r)) | O(d(n+r)) | O(r) | 稳定 |

¹ 折半插入的比较次数 O(n log n)，但移动次数仍是 O(n²)，整体 O(n²)

::: tip 如何选择排序算法

- **要稳定**：归并排序、直接插入、冒泡
- **要省空间**：快排（递归栈）、堆排
- **数据基本有序**：直接插入、冒泡
- **数据量大**：快排、堆排、归并
- **数据量小**（n < 50）：直接插入
:::

## 外部排序

数据量太大，无法全部装入内存，需要在磁盘上进行排序。

### 基本思想

**归并排序**：将数据分为多个小段，每段在内存中排序后写回磁盘，再将各段归并。

### 败者树

用于多路归并时快速选出最小元素，减少比较次数。

- k 路归并：每轮从 k 个段中选出最小元素
- 不用败者树：每轮需要 k-1 次比较
- 使用败者树：每轮只需 ⌈log₂k⌉ 次比较

### 置换-选择排序

用于生成更长的初始归并段，减少归并趟数。

### 最佳归并树

类似哈夫曼树，让归并过程中读写的磁盘块总数最少。

## 高频考点总结

| 考点 | 频率 | 说明 |
|------|------|------|
| 各排序算法手动模拟 | 极高 | 每种排序至少会模拟一趟 |
| 快排 Partition 过程 | 极高 | 给定数组，写出每一趟的结果 |
| 堆排序建堆 + 调整 | 极高 | 给序列建大根堆/小根堆 |
| 稳定性判断 | 高 | 常见选择题考点 |
| 时间/空间复杂度 | 高 | 对比表要背熟 |
| 外部排序磁盘读写次数 | 中 | 归并路数与趟数的关系 |
