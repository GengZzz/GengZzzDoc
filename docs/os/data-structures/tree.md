# 树与二叉树

树是非线性数据结构，反映元素之间的层次关系。二叉树是考试的核心内容，遍历、性质、各种特殊二叉树都是高频考点。

## 树的基本概念

### 定义

树（Tree）是 n 个结点的有限集。n=0 时为空树；非空树中：

- 有且仅有一个**根**结点
- 其余结点可分为 m 个互不相交的有限集，每个集合本身又是一棵树（子树）

```text
        A          ← 根
       / \
      B   C        ← A 的子树
     / \   \
    D   E   F
```

### 基本术语

| 术语 | 含义 |
|------|------|
| 结点的度 | 结点拥有的子树个数（分支数） |
| 树的度 | 树中所有结点的度的最大值 |
| 叶子（终端结点） | 度为 0 的结点 |
| 分支结点 | 度不为 0 的结点 |
| 孩子/双亲 | 结点的子树的根称为该结点的孩子，该结点称为孩子的双亲 |
| 兄弟 | 同一双亲的孩子互称兄弟 |
| 深度/高度 | 树中结点的最大层次数 |
| 有序树/无序树 | 子树之间有/无次序之分 |
| 森林 | m 棵互不相交的树的集合 |

::: tip 度与边数
度为 n 的树：所有结点度数之和 = 结点总数 - 1 = 边的总数。这是做计算题的基础公式。
:::

## 二叉树

### 定义

二叉树是每个结点**至多有两个子树**（左子树和右子树）的有序树。二叉树的子树有左右之分，次序不能颠倒。

```text
二叉树的五种基本形态:

  ① 空    ② 只有根   ③ 右空    ④ 左空    ⑤ 左右都有
                  ○        ○        ○          ○
                 /          \      / \        / \
                ○            ○    ○   ○      ○   ○
```

::: warning 二叉树 vs 度为 2 的树
二叉树允许某个结点只有左子树或只有右子树，而度为 2 的树要求每个结点的度恰好为 2（除了叶子）。二叉树是有序的，度为 2 的树默认无序。
:::

### 二叉树的性质

**性质 1**：第 i 层至多有 2^(i-1) 个结点（i ≥ 1）

**性质 2**：深度为 k 的二叉树至多有 2^k - 1 个结点

**性质 3**：叶子结点数 n₀ = 度为 2 的结点数 n₂ + 1

```text
证明:  n₀ + n₁ + n₂ = n        （结点总数）
       0·n₀ + 1·n₁ + 2·n₂ = n-1 （边总数）
  两式相减: n₀ - n₂ = 1  →  n₀ = n₂ + 1
```

**性质 4**：具有 n 个结点的完全二叉树的深度为 ⌊log₂n⌋ + 1

**性质 5**：对完全二叉树按层编号（从 1 开始），结点 i：

- i 的双亲：⌊i/2⌋（i > 1）
- i 的左孩子：2i（2i ≤ n 时存在）
- i 的右孩子：2i+1（2i+1 ≤ n 时存在）

### 特殊二叉树

**满二叉树**：深度为 k 且有 2^k-1 个结点的二叉树。每一层都是满的。

```text
深度 3 的满二叉树:

          1          ← 第 1 层
        /   \
       2     3       ← 第 2 层
      / \   / \
     4   5 6   7     ← 第 3 层
```

**完全二叉树**：按层编号后，编号与同深度满二叉树一一对应（从上到下、从左到右连续，中间没有空位）。

```text
完全二叉树:              不是完全二叉树:

      1                        1
     / \                      / \
    2   3                    2   3
   / \  /                   /     \
  4   5 6                  4       7
（连续编号 1-6）         （缺 5、6，不连续）
```

### 存储结构

**顺序存储**：按层编号存入数组，适用于完全二叉树。

```c
#define MaxSize 100
typedef struct {
    ElemType data[MaxSize];  // data[0] 不用，从 data[1] 开始
    int n;                   // 结点数
} SqBiTree;
// 结点 i 的左孩子: 2i, 右孩子: 2i+1, 双亲: i/2
```

::: tip 顺序存储的缺陷
对于一般的二叉树，顺序存储会浪费大量空间。最坏情况下（单支树），深度为 k 的树需要 2^k-1 个存储位置。
:::

**链式存储**（二叉链表）：

```c
typedef struct BiTNode {
    ElemType data;
    struct BiTNode *lchild, *rchild;
} BiTNode, *BiTree;
```

## 二叉树遍历

遍历是按照某种规则访问树中每个结点恰好一次。二叉树有四种遍历方式。

### 先序遍历（根-左-右）

```c
void PreOrder(BiTree T) {
    if (T != NULL) {
        visit(T);           // 访问根
        PreOrder(T->lchild); // 遍历左子树
        PreOrder(T->rchild); // 遍历右子树
    }
}
```

### 中序遍历（左-根-右）

```c
void InOrder(BiTree T) {
    if (T != NULL) {
        InOrder(T->lchild);
        visit(T);           // 访问根
        InOrder(T->rchild);
    }
}
```

### 后序遍历（左-右-根）

```c
void PostOrder(BiTree T) {
    if (T != NULL) {
        PostOrder(T->lchild);
        PostOrder(T->rchild);
        visit(T);
    }
}
```

### 层序遍历（逐层从左到右）

使用队列实现：

```c
void LevelOrder(BiTree T) {
    if (T == NULL) return;
    LinkQueue Q;
    InitQueue(Q);
    BiTree p;
    EnQueue(Q, T);
    while (!QueueEmpty(Q)) {
        DeQueue(Q, p);
        visit(p);
        if (p->lchild) EnQueue(Q, p->lchild);
        if (p->rchild) EnQueue(Q, p->rchild);
    }
}
```

### 遍历序列推导

**核心规则**：

- 先序序列的第一个元素是**根**
- 后序序列的最后一个元素是**根**
- 在中序序列中，根的左边是左子树，右边是右子树

::: warning 经典题型
已知**先序+中序**或**后序+中序**可以唯一确定一棵二叉树。但**先序+后序**不能唯一确定。

例：先序 `ABDECFG`，中序 `DBEAFGC`

1. 先序首字符 A 是根 → 中序中 A 的左边 `DBE` 是左子树，右边 `FGC` 是右子树
2. 递归处理左子树：先序 `BDE`，中序 `DBE` → B 是根...
3. 递归处理右子树：先序 `CFG`，中序 `FGC` → C 是根...
:::

## 线索二叉树

利用二叉链表中空的 lchild/rchild 指针，存放前驱/后继的地址，加速遍历。

```c
typedef struct ThreadNode {
    ElemType data;
    struct ThreadNode *lchild, *rchild;
    int ltag, rtag;  // 0: 孩子指针, 1: 线索
} ThreadNode, *ThreadTree;
```

```text
中序线索化示例:     D ←→ B ←→ E ←→ A ←→ F ←→ G ←→ C
                   (中序序列的前驱后继关系)
```

**Tag 标记的含义**：

- `ltag=0`：lchild 指向左孩子
- `ltag=1`：lchild 指向前驱（中序）
- `rtag=0`：rchild 指向右孩子
- `rtag=1`：rchild 指向后继（中序）

::: tip 线索化的用途
中序线索二叉树可以实现**无需栈和递归**的中序遍历，空间复杂度 O(1)。408 考试中常考线索化的原理和遍历过程。
:::

## 树与森林

### 树的存储结构

**孩子兄弟表示法**（二叉树表示法）：每个结点存放第一个孩子和下一个兄弟的指针。

```c
typedef struct CSNode {
    ElemType data;
    struct CSNode *firstchild, *nextsibling;
} CSNode, *CSTree;
```

```text
树:                    孩子兄弟表示法:
    A                       A
   /|\                      |
  B C D         →          B → C → D
 /|   |                    |       |
E F   G                    E → F   G
```

::: tip 树 ↔ 二叉树
用孩子兄弟表示法，任何一棵树都可以唯一转换为一棵二叉树。根没有兄弟，所以转换后没有右子树。森林的转换：将各棵树的根视为兄弟。
:::

### 森林与二叉树的转换

- **森林 → 二叉树**：各棵树的根视为兄弟，然后用孩子兄弟法
- **二叉树 → 森林**：根的右链上的所有结点是各棵树的根

### 树和森林的遍历

| 树/森林 | 对应的二叉树遍历 |
|---------|-----------------|
| 先根遍历 | 先序遍历 |
| 后根遍历 | 中序遍历 |
| 森林先序 | 二叉树先序 |
| 森林中序 | 二叉树中序 |

## 哈夫曼树

### 定义

哈夫曼树（Huffman Tree）是带权路径长度（WPL）最小的二叉树。

- **路径长度**：从根到某结点的路径上的分支数
- **带权路径长度**：叶子的权值 × 路径长度
- **WPL**：所有叶子的带权路径长度之和

### 构造算法

贪心策略：每次选择权值最小的两棵树合并。

```text
权值: 2, 3, 4, 7, 8

步骤 1: 合并 2 和 3 → 新结点(5)
步骤 2: 合并 4 和 5 → 新结点(9)
步骤 3: 合并 7 和 8 → 新结点(15)
步骤 4: 合并 9 和 15 → 新结点(24)

结果:
           (24)
          /    \
        (9)    (15)
        / \    / \
      (5)  4  7   8
      / \
     2   3

WPL = 2×3 + 3×3 + 4×2 + 7×2 + 8×2 = 49
```

### 哈夫曼编码

利用哈夫曼树进行编码，频率高的字符用短码，频率低的用长码，实现压缩。

左分支记 0，右分支记 1，从根到叶子的路径即为该字符的编码。

::: tip 哈夫曼编码的前缀码性质
哈夫曼编码是**前缀码**：没有任何编码是另一个编码的前缀。这保证了译码的唯一性。
:::

::: warning 哈夫曼树的性质

1. 没有度为 1 的结点（n₁ = 0）
2. n 个叶子的哈夫曼树有 2n-1 个结点
3. WPL 最小（这是核心考点）
:::

## 二叉搜索树（BST）

### 定义

二叉搜索树（Binary Search Tree）满足：左子树所有结点值 < 根值 < 右子树所有结点值。

```text
       8
      / \
     3   10
    / \    \
   1   6    14
      / \   /
     4   7 13
```

### 查找

```c
BiTNode *BST_Search(BiTree T, ElemType key) {
    while (T != NULL && T->data != key) {
        if (key < T->data) T = T->lchild;
        else T = T->rchild;
    }
    return T;
}
```

**时间复杂度**：O(h)，h 为树的高度。平衡时 O(log n)，退化为链表时 O(n)。

### 插入

```c
bool BST_Insert(BiTree &T, ElemType key) {
    if (T == NULL) {
        T = (BiTree)malloc(sizeof(BiTNode));
        T->data = key;
        T->lchild = T->rchild = NULL;
        return true;
    }
    if (key == T->data) return false;  // 已存在
    if (key < T->data) return BST_Insert(T->lchild, key);
    else return BST_Insert(T->rchild, key);
}
```

### 删除

三种情况：

1. **叶子结点**：直接删除
2. **只有一个孩子**：用孩子替代自己
3. **有两个孩子**：用中序后继（或中序前驱）替代自己，然后删除那个后继

::: tip BST 的中序遍历
二叉搜索树的中序遍历结果是**递增有序序列**。这是 BST 最重要的性质，常用于判断一棵树是否为 BST。
:::

## 平衡二叉树（AVL）

### 定义

AVL 树是任意结点的左右子树高度差（平衡因子）不超过 1 的二叉搜索树。

```c
typedef struct AVLNode {
    ElemType data;
    int height;  // 以该结点为根的子树高度
    struct AVLNode *lchild, *rchild;
} AVLNode, *AVLTree;

int getBalance(AVLNode *node) {
    if (node == NULL) return 0;
    return height(node->lchild) - height(node->rchild);
}
```

### 四种旋转

插入导致不平衡时，需要通过旋转恢复平衡：

| 类型 | 旋转方式 | 场景 |
|------|---------|------|
| LL | 右旋 | 在左子树的左子树插入 |
| RR | 左旋 | 在右子树的右子树插入 |
| LR | 先左旋再右旋 | 在左子树的右子树插入 |
| RL | 先右旋再左旋 | 在右子树的左子树插入 |

```text
LL 型右旋:

      30 (失衡)            20
     /                    /  \
    20          →        10    30
   /
  10

RR 型左旋:

  10 (失衡)                20
    \                     /  \
     20       →          10    30
       \
        30
```

::: warning AVL 的旋转是考试难点
判断旋转类型的方法：从失衡结点出发，沿着插入路径看两个方向。LL 和 RR 只需一次旋转，LR 和 RL 需要两次旋转（先对子树旋转，再对失衡结点旋转）。
:::

## 红黑树

### 定义

红黑树是一种自平衡二叉搜索树，满足以下性质：

1. 每个结点要么是红色，要么是黑色
2. 根结点是黑色
3. 叶子结点（NIL）是黑色
4. 红色结点的两个子结点都是黑色（不能有两个连续的红色）
5. 从任一结点到其每个叶子的所有路径包含**相同数目**的黑色结点

### 与 AVL 的对比

| 对比维度 | AVL 树 | 红黑树 |
|---------|--------|--------|
| 平衡标准 | 高度差 ≤ 1 | 黑高相等 |
| 查找效率 | 更高（更严格平衡） | 略低 |
| 插入/删除 | 可能需要多次旋转 | 最多 3 次旋转 |
| 适用场景 | 查找密集型 | 插入删除密集型 |
| 实际应用 | 数据库索引 | C++ STL map/set、Java TreeMap |

::: tip 红黑树的考试要求
408 考试对红黑树的要求相对较低，通常考：性质判断（是否是红黑树）、插入调整的大致过程。不需要背诵完整的插入删除代码，理解原理即可。
:::

| 考点 | 频率 | 说明 |
|------|------|------|

| 红黑树性质 | 中 | 五条性质、与 AVL 对比 |
