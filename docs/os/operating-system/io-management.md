# I/O 管理

I/O 管理负责协调 CPU、内存与外部设备之间的数据传输。408 考试重点考查 I/O 控制方式、缓冲管理、SPOOLing、磁盘调度。

## I/O 设备分类

| 分类依据 | 类型 | 举例 |
|---------|------|------|
| 信息交换单位 | 字符设备 | 键盘、鼠标 |
| | 块设备 | 磁盘、SSD |
| 数据传输速率 | 低速 | 键盘、鼠标 |
| | 中速 | 打印机 |
| | 高速 | 磁盘、网卡 |
| 共享属性 | 独占设备 | 打印机 |
| | 共享设备 | 磁盘 |
| | 虚拟设备 | SPOOLing 模拟 |

## I/O 控制方式

| 方式 | CPU 参与度 | 数据单位 | 适用场景 |
|------|-----------|---------|---------|
| 程序查询 | 全程等待 | 字 | 低速简单设备 |
| 程序中断 | 每字节中断一次 | 字 | 中低速设备 |
| DMA | 仅设置和完成中断 | 数据块 | 高速批量设备 |
| I/O 通道 | 仅启动和结束 | I/O 程序 | 大型机 |

### 程序查询方式

```text
CPU 循环:
  while (1) {
    if (设备状态 == 就绪) {
      读/写数据;
      break;
    }
  }
  // CPU 全程被占用
```

### 程序中断方式

```text
CPU 执行其他任务
  ← 设备就绪 → 发中断 → CPU 响应 → 传输 1 字节 → 返回
  ← 下一个字节就绪 → 再次中断 → ...
```

### DMA 方式

```text
DMA 控制器接管数据传输:
  1. CPU 设置: 源地址、目标地址、传输字节数
  2. DMA 窃取总线周期，直接与内存交换
  3. 传输完成 → DMA 发中断通知 CPU

一次 DMA 请求 → 传输一个数据块（而非一个字）
```

### 通道方式

```text
通道 = 简化的 I/O 处理器，有自己的指令系统

CPU: 启动通道 → 执行通道程序 → 返回
通道: 独立执行 I/O 程序，管理多个设备控制器
```

::: tip 方式演进
程序查询 → 中断 → DMA → 通道，核心趋势是逐步减少 CPU 对 I/O 的干预，从逐字节控制到数据块批量控制。
:::

## 缓冲管理

缓冲区在内存中临时存放 I/O 数据，缓解设备与 CPU 的速度差异。

### 单缓冲

```text
设备 → 缓冲区 → 用户进程

处理一块数据的时间 = max(设备送入时间, 用户处理时间)
```

### 双缓冲

```text
设备 → 缓冲区 A     用户进程从缓冲区 B 读取
     → 缓冲区 B     用户进程从缓冲区 A 读取

设备和用户可并行工作，效率更高
```

### 循环缓冲

多个缓冲区组成环形队列，适用于持续的数据流。

### 缓冲池

统一管理多个缓冲区，按用途分为：

- 空缓冲队列
- 输入队列（装满输入数据）
- 输出队列（装满待输出数据）

系统按需从缓冲池申请和归还缓冲区。

## 设备分配与回收

### 设备控制块 DCB

```text
DCB:
- 设备类型
- 设备标识符
- 设备状态（忙/空闲/故障）
- 指向 COCT 的指针
- 等待队列
```

### SPOOLing 技术

将独占设备虚拟为共享设备。

```text
例: SPOOLing 打印系统

用户进程 → 输出到输入井（磁盘）→ 打印守护进程 → 打印机

           ┌──────────┐
进程 A ──→ │  输入井   │
进程 B ──→ │ (磁盘空间) │──→ 打印进程 ──→ 打印机
进程 C ──→ │          │
           └──────────┘

效果: 多个进程可同时"打印"，实际由打印进程排队输出
```

::: tip SPOOLing 的本质
用高速磁盘空间模拟低速独占设备。打印机是独占设备，但通过 SPOOLing，每个进程都认为自己独占了打印机（实际是写文件）。这是**虚拟设备技术**。
:::

## 磁盘调度算法回顾

| 算法 | 寻道策略 | 饥饿？ |
|------|---------|--------|
| FCFS | 按请求顺序 | 否 |
| SSTF | 找最近的磁道 | 是（远端磁道可能永远等不到） |
| SCAN | 单方向扫描到底再折返 | 否 |
| C-SCAN | 单方向扫描，回程快速跳回 | 否 |
| LOOK | SCAN 的优化，无请求即折返 | 否 |
| C-LOOK | C-SCAN 的优化 | 否 |
