## 计划内容

- **鉴权与授权**：Session / JWT / OAuth2 / OIDC、RBAC / ABAC
- **常见漏洞**：XSS、CSRF、SQL 注入、SSRF、越权（OWASP Top 10）
- **加密基础**：对称/非对称、哈希与加盐、签名、证书链
- **传输安全**：TLS 握手、HTTPS、HSTS、防中间人
- **密钥与凭据管理**：密钥轮换、密钥库、最小权限
- **防护实践**：输入校验、输出编码、速率限制、安全响应头
