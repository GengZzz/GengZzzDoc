## 计划内容

- **三大支柱**：日志（Logs）、指标（Metrics）、链路追踪（Traces）
- **日志**：结构化日志、级别、采集与检索（ELK）
- **指标**：Prometheus、四大黄金信号、RED / USE 方法
- **链路追踪**：OpenTelemetry、TraceID 透传、采样
- **告警**：告警规则、降噪、SLO / SLA / 错误预算
- **实践**：可观测性驱动排障、Dashboard 设计
