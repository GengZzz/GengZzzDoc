# 系统设计

::: warning 🚧 本页建设中
以下为计划覆盖的内容大纲。欢迎通过 issue 或 PR 补充。

## 计划内容

- **容量评估**：QPS / TPS 估算、读写比、存储增长、带宽
- **缓存**：缓存模式（Cache-Aside / Read-Through）、击穿/穿透/雪崩、一致性
- **限流与降级**：令牌桶/漏桶、熔断、隔离、优雅降级
- **数据一致性**：强一致 vs 最终一致、CAP / BASE、幂等设计
- **典型场景**：短链、秒杀、Feed 流、排行榜、订单超时
- **方法论**：需求澄清 → 容量估算 → 接口与存储 → 扩展点 → 取舍
