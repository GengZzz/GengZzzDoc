- **开通与构建**：仓库开启 Pages、选择分支/目录、强制 HTTPS
- **VitePress 适配**：`base` 配置与仓库路径一致、产物输出目录
- **自动化部署**：结合 `.workflow/` 或 Gitee Go 实现推送即部署
- **常见问题**：缓存刷新、404、资源路径错乱、需手动更新部署
- **与 GitHub Pages 对比**：访问速度、备案要求、更新机制差异
