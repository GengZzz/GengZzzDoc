# React

React 是一个用于构建用户界面的 JavaScript 库，由 Meta（Facebook）开发和维护。它采用声明式、组件化的编程模型，通过虚拟 DOM 高效更新视图。

## React 简介

**核心特性：**

| 特性 | 说明 |
|------|------|
| 声明式 | 描述 UI 应该是什么样子，React 负责如何更新 |
| 组件化 | UI 拆分为独立、可复用的组件 |
| 虚拟 DOM | 在内存中维护 DOM 副本，最小化真实 DOM 操作 |
| 单向数据流 | 数据从父组件流向子组件 |
| JSX | 在 JS 中编写类似 HTML 的语法 |
