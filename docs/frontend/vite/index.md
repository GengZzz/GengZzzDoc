# Vite

Vite 是下一代前端构建工具，由 Vue 作者尤雨溪开发。它利用浏览器原生 ESM 实现极速的开发服务器启动，使用 Rollup 进行生产构建。

## Vite 简介

**核心优势：**

| 特性 | 说明 |
|------|------|
| 极速启动 | 按需编译，冷启动无需打包 |
| 热更新 | 基于 ESM 的 HMR，只更新修改的模块 |
| 丰富功能 | TypeScript、CSS 预处理器、静态资源处理开箱即用 |
| 优化构建 | 生产环境使用 Rollup，输出高度优化的静态资源 |

::: tip Vite vs Webpack
Webpack 在开发时需要先打包整个应用再启动服务器，项目越大启动越慢。Vite 利用浏览器原生 ESM，开发时不做打包，只有在浏览器请求时才编译对应的模块。
:::
