# 前端

这里记录前端开发的核心技术栈，从基础语言到框架工具，持续更新。

## 学习路线

```
HTML → CSS3 → JavaScript → TypeScript → Vue/React → 工程化
```

| 技术 | 说明 | 入口 |

| [HTML](./html/) | 文档结构、语义化、表单、Web Components | [开始学习](./html/) |

| [JavaScript](./javascript/) | 语言基础、异步、原型、DOM、ES6+ | [开始学习](./javascript/) |
