# 后端框架

后端框架这一组文档聚焦 Java 服务端日常开发中最常见的基础设施能力。

学习顺序建议是：

1. 先看 [Spring](./spring)：理解 IoC、AOP、事务这些底层能力。

后续会继续补充 Spring Boot 和 MyBatis，把工程启动治理、SQL 映射和 Spring 体系集成串起来。

## 学习主线

| 技术 | 重点问题 | 日常开发落点 |
| --- | --- | --- |
| Spring | 对象如何创建、装配、代理和参与事务 | Bean 生命周期、依赖注入、AOP、声明式事务 |
